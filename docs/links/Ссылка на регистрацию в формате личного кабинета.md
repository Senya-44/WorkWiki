# Ссылка на регистрацию в формате личного кабинета

## 📎 Общее описание

Ссылки на регистрацию в формате личного кабинета, представляют собой ссылки на регистрационные формы, переход на которые происходит через авторизацию в личном кабинете. При переходе по такой ссылке, пользователь **обязательно** авторизуется в личном кабинете, после чего попадает на страницу регистрационной формы на мероприятие. При этом, в регистрационную форму автоматически могут подставляться данные из личного кабинета.

## ⚙️ Описание структуры ссылки

**В 1С находится ссылка на регистрацию в формате «registration».**

Например:

<https://registration.phtl.ru/index.php?q=0428ef0e-97e9-11f1-a85f-005056b8fc44&q1=6dfc4380-8f0c-11f0-8fd8-005056b872b3>

При использовании такой ссылки, переход в личный кабинет не происходит. Поэтому, если в регистрационной форме используется подстановка данных из личного кабинета (например, ФИО) – поля остаются пустыми и не активными для заполнения.

**Для создания ссылки в формате личного кабинета, необходимо, чтобы переход происходил через** <https://lk.phtl.ru>

В таком случае, переход к регистрации на мероприятие, происходит принудительно, через предварительную регистрацию или авторизацию в личном кабинете.

## ✅ Составление ссылки

Для составления ссылки необходимо:

1. Взять ссылку на регистрационную форму в 1С;
2. Вместо  
   <https://registration.phtl.ru/index.php>  
   Подставить  
   <https://lk.phtl.ru/>
3. После первого q поставить 1. То есть, вместо записи  
   `?q=`  
   Будет запись  
   `?q1=`
4. Заменить q1 на q2. То есть, вместо записи  
   `&q1=`  
   Будет запись  
   `&q2=`

Таким образом, ссылка на регистрацию из 1С, в формате личного кабинета будет выглядеть как:

<https://lk.phtl.ru/?q1=0428ef0e-97e9-11f1-a85f-005056b8fc44&q2=6dfc4380-8f0c-11f0-8fd8-005056b872b3>
