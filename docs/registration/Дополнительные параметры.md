## 📎 Дополнительные параметры


Для динамических участников существует один **основной участник**, который выступает в качестве дополнительного параметра для всех динамических.

### ⚫ Необязательные параметры

Если дополнительные параметры **не являются обязательными**, они могут быть перечислены напрямую, а затем добавлены к участнику:

```1c
ГородУчастника = Анкета.form.Customer.city;[1]
НовыйДоппараметр = Доппараметры.Добавить();
НовыйДоппараметр.ПараметрИмя = "Город";
НовыйДоппараметр.Значение = ГородУчастника;
```

### ⚫ Обязательные параметры

Обязательные параметры не всегда требуются в анкете. Так, например, существует дата рождения, которая может не запрашиваться в анкете, но является обязательным параметром для 1С.

В случае, если параметр обязательный для 1С **и запрашивается** в регистрационной форме - он записывается в дополнительные параметры, как и всегда. В таком случае, дополнительных указаний не требуется.

Если дополнительный параметр является обязательным, но **не требуется для анкеты**, необходимо указать `Неопределено`:

```1c
ФизлицоСтрукт = ЗаполнитьДоппараметры(
    НовыйУчастникДоп,
    ДопПараметрыУчастника,
    ПроведениеМероприятияОбъект,
    МакетАнкеты,
    Неопределено,
    ОтложенноеЗаполнениеУчастников
);
```
