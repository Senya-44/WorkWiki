# Регистрационная форма — с буфером и без динамического добавления

## 📌 Базовый шаблон

**Шаблон макета анкеты:** Тест нагрузки_  
**Код:** `000000344`

## Важно
При динамическом добавлении строка **ОБЯЗАТЕЛЬНО** указывается внутри цикла с пометкой `ОтложенноеЗаполнениеУчастников`.

## 📎 Начальная настройка
Для организации первичной записи в буфер, необходимо установить галочку на против параметра «Отложенное заполнение участников» при создании мероприятия в 1С.


Также, для корректной работы анкеты, необходимо соблюдение параметров алгоритма. Не все строки алгоритма работают корректно для буфера.
