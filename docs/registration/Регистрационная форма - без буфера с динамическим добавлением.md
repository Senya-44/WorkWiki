# Регистрационная форма — без буфера с динамическим добавлением

## 📌 Базовый шаблон

**Шаблон:** Общая форма - Динамический список гостей без записи основного участника  
**Код:** `000000333`

---

## ⚙️ Общий принцип

Динамическое добавление гостей из регистрационной формы, без добавления основного участника и записью его в доп. параметры.


В форме вносится ФИО участника, его дополнительные параметры, список гостей для данного участника. В список участников мероприятия в 1С вносится только список гостей для данного участника, без ФИО самого участника (оно вносится в дополнительные параметры).

### Алгоритм

```
// Изменили обращение к полю с Class на klass в соответствии с новым JSON
КлассУчастника = анкетаСтрукт.form[3].klass;
НовыйДоппараметр = Доппараметры.Добавить(); 
НовыйДоппараметр.ПараметрИмя = "Класс";
НовыйДоппараметр.Значение = КлассУчастника;

ФИОАбитуриента = анкетаСтрукт.form[2].FIOAbiture;
НовыйДоппараметр = Доппараметры.Добавить(); 
НовыйДоппараметр.ПараметрИмя = "Абитуриент";
НовыйДоппараметр.Значение = ФИОАбитуриента;


СтатусыРассмотренияЗаявки = Перечисления.СтатусыРассмотренияЗаявки.Принят;
КолвоУчастников = 0;

ОсновнойУчастник = Неопределено;
GUIDСтрокиОсновногоУчастника = "";

ВсеУчастники = Новый Массив;

Если анкетаСтрукт.form[4].Свойство("User") Тогда
    ВсеУчастники.Добавить(анкетаСтрукт.form[4].User[0]);
КонецЕсли;

Если анкетаСтрукт.form[5].Свойство("Parents") Тогда
    Для каждого Гость Из анкетаСтрукт.form[5].Parents Цикл
        ВсеУчастники.Добавить(Гость.parent[0]);
    КонецЦикла;
КонецЕсли;

Для каждого УчастникСтрукт Из ВсеУчастники Цикл

    КолвоУчастников = КолвоУчастников + 1;

    СтруктФизлицо = РаботаСФизлицами.СтруктураДанныхФизлица();
    СтруктФизлицо.Фамилия = УчастникСтрукт.lastname;
    СтруктФизлицо.Имя     = УчастникСтрукт.name; 
    СтруктФизлицо.Отчество = УчастникСтрукт.surname;

    НовыйУчаст = ДобавитьСтрокуФизлица(СтруктФизлицо, ПроведениеМероприятияОбъект, Цена, СтатусыРассмотренияЗаявки);

    Если КолвоУчастников = 1 Тогда
        ОсновнойУчастник = НовыйУчаст.УчастникМероприятия;
        GUIDСтрокиОсновногоУчастника = НовыйУчаст.GUIDСтроки;
        
        НовыйУчастник = НовыйУчаст; 
    КонецЕсли;

    НовыйУчаст.ОсновнойУчастник = ОсновнойУчастник;
    НовыйУчаст.GUIDСтрокиОсновногоУчастника = GUIDСтрокиОсновногоУчастника;

    ФизлицоСтрукт = ЗаполнитьДоппараметры(НовыйУчаст, Доппараметры, ПроведениеМероприятияОбъект, МакетАнкеты);
    ФизлицоСсылка = ФизлицоСтрукт.физлицо; 

КонецЦикла;
```
---

### Важное правило
При адаптации алгоритма под другие формы, важно изменение порядкового номера form\[0\].

Порядковый номер должен соответствовать порядковому номеру структурного элемента в регистрационной анкете.
