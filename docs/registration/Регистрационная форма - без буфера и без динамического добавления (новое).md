Регистрационная форма может быть с прямым добавлением участников в мероприятие и с добавлением через буфер.

Регистрационные формы, также, могут быть с добавлением одного участника в форму и с динамическим.

При добавлении любого участника (одного или динамического), обязательно указывается строка добавления участника с пометкой «ОтложенноеЗаполнениеУчастников»

Шаблон: Спектакль «Я полюбил страдание»

Код: 000000296

Алгоритм:

| СтатусыРассмотренияЗаявки = Перечисления.СтатусыРассмотренияЗаявки.Принят; НовыйУчастник = ДобавитьСтрокуФизлица(СтруктФизлицо, ПроведениеМероприятияОбъект, Цена, СтатусыРассмотренияЗаявки, ОтложенноеЗаполнениеУчастников ); |
| --- |

Обязательно нужно добавлять строку «Новый участник», содержащую суммарное значение по полям регистрационной анкеты.

| СтатусыРассмотренияЗаявки = Перечисления.СтатусыРассмотренияЗаявки.Принят; НовыйУчастник = ДобавитьСтрокуФизлица(СтруктФизлицо, ПроведениеМероприятияОбъект, Цена, СтатусыРассмотренияЗаявки, ОтложенноеЗаполнениеУчастников ); |
| --- |

Если переменная названа иначе, не «СтатусыРассмотренияЗаявки» - внести актуальное название.

При динамическом добавлении участников, добавление строки ОБЯЗАТЕЛЬНО указывается внутри цикла с пометкой «ОтложенноеЗаполнениеУчастников»

Важно корректно указать добавление дополнительных параметров для динамических участников. Как правило, для динамических участников существует один основной участник. Данный участник выступает в качестве дополнительного параметра для всех динамических.

Для регистрационных форм существуют обязательные параметры и не обязательные.

Дополнительные параметры участника, **если не являются обязательными**, могут быть перечислены напрямую, а затем добавлены к участнику. Для этого необходимо завести дополнительные параметры, указав их источник в поле формы.

| ГородУчастника = Анкета.form\[2\].Customer\[0\].city; НовыйДоппараметр = Доппараметры.Добавить(); НовыйДоппараметр.ПараметрИмя = "Город"; НовыйДоппараметр.Значение = ГородУчастника; |
| --- |

**Если дополнительный параметр является обязательным**, **но не требуется** для анкеты, необходимо указать «неопределено» в списке параметров строки.

| ФизлицоСтрукт = ЗаполнитьДоппараметры(НовыйУчастникДоп, ДопПараметрыУчастника, ПроведениеМероприятияОбъект, МакетАнкеты, Неопределено, ОтложенноеЗаполнениеУчастников); |
| --- |
