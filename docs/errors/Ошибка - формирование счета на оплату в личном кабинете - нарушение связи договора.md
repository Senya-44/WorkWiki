# Ошибка - ЛК - Нарушение связи договора
## 📌 Общее описание

Ошибка возникает в ЛК, на стороне пользователя, при формировании ссылки на оплату.
Пользователь переходит в раздел «Платежи» -> «Оплатить», после чего получает оповещение об ошибке:
«Не удалось получить ссылку на оплату. Попробуйте позже. Нарушение связи договора и мероприятия»

---
---

## ⚠️ Описание причины возникновения ошибки

Ошибка происходит из-за появления в 1С двух договоров на одного человека в одном мероприятии. Предполагается наличие только одного действующего договора.

---
---

## ⚙️ Способ исправления ошибки

Для исправления ошибки необходимо удалить один договор. Перед этим убедитесь:

1. **GUID договора** соответствует GUID в этапе регистрации в 1С
2. В **действующем договоре** присутствуют начисления

---

### 🔍 Шаг 1. Определение нужного договора

Чтобы из двух (или более) договоров определить нужный:

1. Перейдите в раздел **«Статусы этапов отбора»** в 1С
2. Найдите человека, по которому была получена ошибка
3. Определите **GUID** (в рамках того мероприятия, по которому получена ошибка; если человек зарегистрирован на несколько мероприятий)
4. Перейдите в мероприятие, в котором участвует человек (**«Проведение мероприятий»**)
5. Откройте договоры данного человека по данному мероприятию:
   - Найдите человека в мероприятии
   - Выделите его
   - Нажмите на кнопку **«Договор»**
6. Найдите среди договоров тот, у которого **GUID совпадает** с GUID строки из «Статусов отбора»

---

### 💰 Шаг 2. Проверка и перенос начислений

Убедитесь, что начисления проведены по нужному договору.

> **Если начисления на другом договоре**, а нужный договор — без начислений, необходимо перенести начисления.

**Порядок действий:**

1. Перейдите в договор **с начислениями**
2. Откройте договор **без начислений** (нужный)
3. Нажмите на кнопку **«Создать начисление»** в договоре без начислений
4. Внесите данные, идентичные тем, которые указаны в договоре с начислениями

   > ⚠️ **Важно:** При использовании кнопки «Движения по договору» перенос данных будет осуществлён **вместе с номером договора**, поэтому такой перенос **НЕ исправит** ошибки

5. Сохраните созданное начисление
6. Удалите начисление из договора, в котором были начисления, но который признан неактуальным

---

### ✅ Шаг 3. Проверка результата

Проверить корректность совершённых действий можно через личный кабинет:

1. Включите просмотр **от лица пользователя**
2. Убедитесь в корректности работы кнопки **оплаты**
