# Ошибка - ЛК - Нарушение связи договора
## 📌 Общее описание

Ошибка возникает в ЛК, на стороне пользователя, при формировании ссылки на оплату.
Пользователь переходит в раздел «Платежи» -> «Оплатить», после чего получает оповещение об ошибке:
«Не удалось получить ссылку на оплату. Попробуйте позже. Нарушение связи договора и мероприятия»

---

## ⚠️ Описание причины возникновения ошибки

Ошибка происходит из-за появления в 1С двух договоров на одного человека в одном мероприятии. Предполагается наличие только одного действующего договора.


## ⚙️ Способ исправления ошибки
Для исправления ошибки, необходимо удалить один договор. При этом, необходимо удостовериться:
1.	В соответствии GUID договора и GUID в этапе регистрации в 1С;
2.	В наличии в действующем договоре начислений.
Для того, чтобы из двух (или более) договоров определить нужный, необходимо:
1.	Перейти в раздел «Статусы этапов отбора» в 1С;
2.	Найти человека, по которому была получена ошибка;
3.	Определить GUID (в рамках того мероприятия, по которому получена ошибка, если человек зарегистрирован на несколько мероприятий);
4.	Перейти в мероприятие, в котором участвует человек («Проведение мероприятий»);
5.	Открыть договоры данного человека по данному мероприятию (Найти человека в мероприятии, выделить его и нажать на «Договор»);
6.	Найти среди договоров тот, у которого GUID совпадает с GUID строки из «Статусов отбора».
Далее, необходимо убедиться, что начисления проведены по данному договору.
Если начисления были получены на другой договор, а нужный договор – без начислений, необходимо перенести начисления с договора с начислениями, на нужный.
Для этого:
1.	Перейти в договор с начислениями;
2.	Открыть договор без начислений;
3.	Нажать на кнопку «Создать начисление» в договоре без начислений;
4.	Внести данные, идентичные тем, которые указаны в договоре с начислениями. При использовании кнопки «Движения по договору» перенос данных будет осуществлен ВМЕСТЕ с номером договора, поэтому такой перенос НЕ исправит ошибки;
5.	Сохранить созданное начисление;
6.	Удалить начисление из договора, в котором были начисления, но который был признан неактуальным.
Проверить корректность совершенных действий можно через личный кабинет, включив просмотр от лица пользователя и удостоверившись в корректности работы кнопки опалты.
