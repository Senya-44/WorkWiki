    Регистрационные формы на мероприятия могут быть:

    • С предварительной записью в буфер;
    • С прямой записью в мероприятие.

    Для каждого типа регистрации, анкета может быть:

    • С динамическим добавлением гостей;
    • Без динамического добавления.

    Таким образом, существует четыре основных варианта регистрации:

    • Регистрация через буфер с динамическим добавлением
    • Регистрация через буфер без динамического добавления
    • Регистрация без буфера с динамическим добавлением участников
    • Регистрация без буфера и без динамического добавления, с прямой записью в мероприятие

    При записи через буфер, добавление участников в мероприятие происходит не напрямую, а через буферный регистр на этапе 1С.

    Первичное добавление в буфер позволяет избежать ошибок регистрации при высокой нагрузке.

    Шаблон регистрации: Тест нагрузки

    Код: 000001229

    Для организации первичной записи в буфер, необходимо установить галочку на против параметра «Отложенное заполнение участников» при создании мероприятия в 1С.

    При динамическом добавлении участников, важно указывать запись каждого участника из массива в буфер. При этом, в буфер участник записывается с данными из анкеты и ссылкой на название мероприятия.

    Основной участник, также, записывается в мероприятие через буфер. Для этого, при его создании, также используется запись «ОтложенноеЗаполнениеУчастников».

    Добавлять запись «ОтложенноеЗаполнениеУчастников» не требуется, но нужно установить галочку отложенной записи в самом мероприятии.

    Регистрация без буфера и без динамического добавления, с прямой записью в мероприятие

    Шаблон: Спектакль «Я полюбил страдание»

    Код: 000000296

    Алгоритм:

    СтатусыРассмотренияЗаявки = Перечисления.СтатусыРассмотренияЗаявки.Принят; НовыйУчастник = ДобавитьСтрокуФизлица(СтруктФизлицо, ПроведениеМероприятияОбъект, Цена, СтатусыРассмотренияЗаявки, ОтложенноеЗаполнениеУчастников );

    Обязательно нужно добавлять строку «Новый участник», содержащую суммарное значение по полям регистрационной анкеты.

    СтатусыРассмотренияЗаявки = Перечисления.СтатусыРассмотренияЗаявки.Принят; НовыйУчастник = ДобавитьСтрокуФизлица(СтруктФизлицо, ПроведениеМероприятияОбъект, Цена, СтатусыРассмотренияЗаявки, ОтложенноеЗаполнениеУчастников );

    Если переменная названа иначе, не «СтатусыРассмотренияЗаявки» - внести актуальное название.
